[Gulp] 在 Gulp 项目中引入 EJS template

发表于 2020-05-25 分类于 Gulp Disqus：

这篇文章是我在开始工作前学习 Gulp 与 EJS 时的笔记，现在的公司虽然不是用 Gulp 也不是用 EJS，而是采用一个电商后台服务 Shopify 自创的模板语言（liquid），但因为同为模板语言，因此让我想起曾写过这篇跟 EJS 有关的笔记，所以就拿来发铁人赛啦～

如何在 Gulp 项目中安装 EJS 可以参考这是在讲 Gulp 不是饮料是任务自动化工具这件事之番外篇：加入 ejs 篇。

以下内容关于是如何在项目中撰写 EJS。

gulpfile.js

如果有需要加载其他套件的 js 档，需要再写一个段落来集成。

项目文件夹结构

  • index 文件夹：各区块的 .ejs 档，每个档里面的内容都是用 HTML 标签撰写的，且每个档名开头都是 _，例如 _footer.ejs。
  • layout 文件夹：放一些共用的内容，例如 <head> 中的信息、所有要加载的 CDN <script> 等。
  • index.ejs：把以上两个文件夹中所有 .ejs 排成一个完整的网页。

index.ejs

引入其他的 .ejs 档，要用 <%- include ('路径') %> 标签。
