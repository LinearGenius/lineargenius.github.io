[Gulp] 安装 PostCSS 的地雷

发表于 2020-03-10 分类于 Gulp Disqus：

最近在学怎么使用 Gulp 来管理项目，于是按照 Ray 的教学文慢慢跟着写 gulpfile，不过在安装 PostCSS 时有踩到一个文章中没提到的地雷，解决的过程一波二折，于是让我决定记录一下拆地雷的经过。

问题描述

在 Ray 的教学文：这是在讲 Gulp 不是饮料是任务自动化工具这件事：安装 PostCSS 篇中，有提到要安装 gulp-cssnano，并且将它引入 gulpfile 中。

我照做之后，执行 gulp scss，此时出现一个错误信息：

Error in plugin “gulp-postcss”
Message: [object Object] is not a PostCSS plugin

尝试解决

由于在 Ray 的教学文章中没有提到会发生这个错误，所以我就自行估狗了一些 StackOverflow 的文章，试了好几篇解答后，终于找到了一个能成功解决问题的回答！

就是这一篇：gulpfile autoprefixer must change to postcss

压缩 CSS 时又报错

改了 require 之后，我接着处理 CSS 的压缩以及判断开发环境与正视环境，结果在输入 gulp scss --env prod 时又跳出错误：
