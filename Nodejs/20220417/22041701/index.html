[Node.js] 从零搭建一个可维护的 REST API

发表于 2022-04-17 分类于 Node.js Disqus：

能返回 JSON 的服务不等于可维护的 API。随着接口增加，路由、业务规则和数据库操作需要明确分工。

三层结构

  • route/controller：读取请求并写回响应。
  • service：处理业务规则，不依赖 HTTP。
  • repository：集中数据库查询。

控制器保持短小，service 才是主要测试对象。

先校验输入

进入业务逻辑前校验参数。缺少字段返回 400，没有权限返回 403，资源不存在返回 404；服务器内部错误才使用 500。

统一响应与错误

成功响应使用稳定的 data 结构，错误响应包含机器可判断的 code 和给用户看的 message。不要把堆栈返回给浏览器。

配置来自环境变量

端口、数据库地址和密钥应从 process.env 读取，并在启动时一次性校验。缺失关键配置时直接退出，比运行到请求阶段才报错更容易排查。
