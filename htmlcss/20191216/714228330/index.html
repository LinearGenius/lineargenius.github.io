[CSS] 浮动 (float) 与清除浮动 (clear)

发表于 2019-12-16 更新于 2019-12-21 分类于 HTML&CSS Disqus：

由于老师耳提面命，float 及 clear 是网页排版的基石之一，所以决定来汇整一下相关的资料，刚好某种程度上也可以承接上一篇的主题。

float 属性的使用时机

使用诸如 <div> 之类的区块元素排版时，默认的排列方式都是由左至右、由上至下。但如果我们今天想要做的是多栏式排版，或是让多个区块元素并排时，就需要使用 float 属性。

float 属性的值

浮动方向可以用的值有 left、right、none（默认值，也就是不浮动）以及 inherit（继承自父层的属性），最后这个 inherit 尽量不要使用，避免 IE 不支持的情况发生。

clear 属性的使用时机

如果想控制浮动元素的排版，就一定要懂 clear 属性的操作方式。

有时候，浮动元素在前，而后面的元素没有使用浮动时，后面的元素就会往上跑、叠在前一个元素的下方；有时候，父层内的元素使用浮动，会让父层包不住子元素。

遇到这种情形时，就要使用 clear 属性来处理跑版问题。

clear 属性的使用方法

clear 属性可以用的值有 left、right、both、none 以及 inherit（IE不支持）， 其中以 both 最常用。

clear 属性可以有 3 种使用方法：

  1. 在浮动元素的后面多加一个 <div>（命名为 .clearfix），并在 .clearfix 使用 clear: both 语法。
  2. 在要清除浮动内容的父层多加一个 .clearfix 并使用伪元素。★
  3. 在浮动元素后面的区块元素加上 clear: both。

使用 clear 属性须注意，在 <ul><li> 结构中，必须在 <ul> 父元素清除子元素，没办法在 <li> 后面插入 .clearfix。
