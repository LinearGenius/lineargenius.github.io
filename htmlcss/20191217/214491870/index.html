[CSS] CSS3 flex 属性

发表于 2019-12-17 更新于 2019-12-21 分类于 HTML&CSS Disqus：

我是在学习 Bootstrap 4 时才真正接触到这个 CSS3 的属性，在此之前都是用 float 属性在排版。但是用 float 的缺点就是清除浮动很麻烦，如果能够掌握 flex 属性的话就能解决这个问题，而且真的能够更加「弹性」地排版。

以下．就让我们来了解 flex 属性吧！

轴线观念

以前学到的 float 只能水平排列，现在学到的 flex 能够同时做到水平跟垂直排列，也因此衍生出不同对齐方式，所以使用了 flex 的元素也就有了「轴线」这个东西。

在默认的情况下，水平方向的轴线称为主轴线，垂直方向的轴线称为交错轴，两种轴线都有起点跟终点，对象会从主轴线起点（左到右）开始排列。

必须注意的是，当对象排列的方向改变时（上到下），主轴线跟交错轴的方向就会交换，垂直的轴线变成主轴线、水平的轴线变成交错轴。

一览 flex 相关属性

可以用外层属性或内层属性来分类，也可以用是否为对齐方法来分类。
粗体为特别重要的属性。

外层属性

  • display - 必备属性，声明 flex 排版
  • flex-flow
    • flex-direction - 决定 flex 轴线
    • flex-wrap - 决定换行的属性
  • justify-content - 主轴线的对齐
  • align-items - 交错轴的对齐

内层属性

  • flex
    • flex-grow - 伸展比
    • flex-shrink - 收缩比
    • flex-basis - 绝对值
  • order - 排序
  • align-self - 单一对象的交错轴对齐

对齐方法

flex-direction 属性

决定主轴线方向，共有四个值。

  • row：默认值，对象将沿着主轴线由左到右排列
  • row-reverse：反转主轴线，对象将沿着主轴线由右到左排列
  • column：将主轴线由水平改为垂直，对象将由上至下排列
  • column-reverse：将主轴线由水平改为垂直，对象将由下至上排列

justify-content 属性

依据主轴线决定内层对象之间的间隔方式。共有五个值。

  • flex-start：所有内层对象对齐主轴线起点
  • flex-end：所有内层对象对齐主轴线终点
  • center：所有内层对象置中在主轴在线
  • space-between：内层对象头尾在主轴线起讫点，其余对象等距对齐
  • space-around：所有内层对象之间等距对齐

align-items 属性

依据交错轴决定内层对象的垂直对齐方式。共有五个值。

  • flex-start：所有内层对象对齐交错轴起点
  • flex-end：所有内层对象对齐交错轴终点
  • center：所有内层对象在交错轴上置中
  • baseline：跟文字行高有关，用文字的基准线作排列（很少用）
  • stretch：所有内层对象拉高，由交错轴起点拉到终点

align-self 属性

个别的内层组件本身的垂直对齐方式，此属性的值跟 align-items 一模一样。

对齐以外的其他属性

flex-wrap 属性（外层）

决定对象超出范围时要不要换行。

See the Pen bs flex flex-wrap by 马维君 (@gretema) on CodePen.

范例中，原本 .col-* 会被 .row 包裹，但因为 Bootstrap 已经帮 .row 内建 flex-wrap 换行了，所以改用 .d-flex 包裹 .col-*。

align-content（外层）

只有在换行（flex-wrap）的情况下可使用，用在有高度的外层容器上，会使内层对象在父元素内垂直对齐。

See the Pen bs flex align-content by 马维君 (@gretema) on CodePen.

order 属性（内层）

用来更改区块排列的顺序，将 order-* 写在 class 里，* 代表我们希望区块排列的顺序。

See the Pen bs flex order by 马维君 (@gretema) on CodePen.
