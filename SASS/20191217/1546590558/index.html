什么是 SASS？

SASS 是一种针对 CSS 的脚本程序语言，借由提供程序语言的特性，例如变量、巢状结构、混合、函数与扩充（继承）等等，可以预先对 CSS 进行结构化的工作，最后再编译可使用于网页上的 CSS 语法。需要搭配 SASS 解译器 (如 prepros) 进行撰写。

SASS 包括两套语法。最开始的语法叫做「缩排语法」，使用缩排来区分代码块，并且用换行将不同规则分隔开，附档名为 .sass。而较新的语法叫做「SCSS」，使用和 CSS 一样的块语法，即使用大括号将不同的规则分开，使用分号将具体的样式分开。

拆档：@import 让每支 .scss 档各司其职

  1. 一支 .scss 文件只单独处理一件事，例如 reset 写在一个 .scss 档，档名命名为 _reset.scss；首页样式写在另一个档，档名命名为 _index.scss。前面加底线很重要，代表那是合并用的 sass 档，理论上并不会编译出对应的 .css 档。
  2. 在名为 all 的 .scss 档里做统整，用 @import「依序」汇入个别的 .scss 档。网页中只会引入 all.scss 编译出来的 all.css。
