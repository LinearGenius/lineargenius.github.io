[Vue] Vue Router 配置与运作

发表于 2019-12-26 Disqus：

在 SPA 的架构下，页面切换不是由后端操控，而是由前端模拟路由器来替换画面上的内容。
而我们可以通过 Vue Router 来达成这件事。

Router 是由前端所模拟的路由器

一个使用 Vue Router 的项目会包含三个元素：

  • 进入点：main.js
  • Router 配置文件（前端路由）：router/index.js

Router 构造配置

构造配置用于 index.js 这个文件中，官方文件有介绍更多更详细的方法跟属性可用。

  • routes 对象：官方文件有列出总共有哪些特性可以调整。
  • mode 字符串：决定网址的 # 是否要保留，或是做其他的设置。如果使用 history 模式，可以去除网址中的 #，但是必须配合后端使用。所以基本上还是以默认模式为主即可。
  • base 字符串：根路径设置的地方。
  • linkActiveClass 字符串：当某个路径被启用时会被加上特定的启用 class，在这个特性里可以设置路径启用的 className。
  • linkExactActiveClass 字符串：跟上一个差不多。

自定义切换路由方法

有些行为必须在 AJAX 结束后才去切换画面，此时 router-link 就不一定适用。

举例来说，当我们在电商网站买完东西、结帐送出后，需要进行一些 AJAX 的行为，得到数据后使用一些方法，使网页切换。

此时，我们应该运用组件 methods + Vue Router 的实例方法，来切换画面。

在官方文件的 API / Router 实例方法中，有许多我们能运用的方法，其中较常用的有：

  • router.push()：括号里放入'路径'。
  • router.back()：回到上一页，括号里不需放参数。
  • router.forward()：前进下一页，括号里不需放参数。
  • router.go()：括号里放入数值，代表前进（正数）或后退（负数）的页数。
  • router.replace()：括号里放入'路径'，通过这个方法前往指定路径，将不会记录在浏览器。

应用方式

  1. 在组件写一个 <a>，并绑定一个自定义的事件，通过这个事件来更新路径。
  2. 在组件里添加 methods，使用 router.push() 方法。
