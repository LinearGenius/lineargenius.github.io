变量声明

var 与 let 的区别

  1. 是否会提升
    当我们分别用 var 跟 let 并在声明变量之前调用变量时，var 会显示 undefined，代表内存有预先准备空间；let 则会显示 not defined，代表内存没有预先准备空间。
  2. 作用域不同
    var 是以 function 做分隔，let 是以 block ( {} ) 做分隔。

const

代表常量，唯读，不可再次赋值。但是如果用 const 声明一个对象，可以在之后修改或添加该对象内部的特性，因为对象是传址（参考）而不是传值，所以可以这样做。其他特色与 let 一样。

循环内的 setTimeout()

假如我们希望用 setTimeout 配合循环输出 1~10，而且每次输出都延迟 10 毫秒：

此时循环的计数器 i 是用 var 来声明，则 setTimeout 得到的数字不会是 1~10，而是得到最后的数字 10，为什么会这样呢？

因为 JS 异步的特点，所以 for 循环并不会等到 setTimeout() 结束后才继续，而是一口气跑完 1~10；又因为 var 的作用域是以 function 做切分，setTimeout() 的 i 会从外层去取值，此时的 i 已经是跑完 for 循环的 10 了。

解决方法是改用 let 声明计数器，这样 setTimeout 得到的就会是当下循环跑的数字。

另一种解法：立即函数 (IIFE)

除了改用 let 声明以外，也可以用立即函数包住 setTimeout，并将循环的 i 作为参数传入立即函数中，保留当下的 i 一笔笔输出数字。

展开符号 …

展开符号能够把数组与类数组里的内容给取出来。以下说明展开符号的几个用途。

合并数个数组

在一个新声明的数组中，把展开符号 ... 加在要合并的数组前方，这种合并的方式与使用 concat() 的效果是一样的。

复制数组（浅复制）

数组与对象一样，都是传址（传参考），所以如果将 B 数组指向 A数组，A、B 数组会被视为同一个实体。如此一来，当我们想要修改 B 数组时，就会连 A 数组的内容也修改到。这叫做深复制。

如果只想修改 B 数组的话，就可以用展开符号来复制 A 数组，再进行操作。只传值的复制方式，就是浅复制。

类数组

有些东西外观很像数组，也具有一些数组的特性，但却不是真正的数组，称为类数组，例如用 querySelectorAll() 取出来的 NodeList 会以类数组的形式呈现所有被选择的节点，但它却不是真正的数组。

在新的空数组中，通过展开符号可以复制类数组中的内容，借此将类数组转为真正的数组。

另一个类数组的例子是函数内置的 arguments 对象，arguments 会包含所有传入函数的参数。

其余参数

如果不确定之后要传入函数的参数数量，可以在函数的唯一一个或最后一个参数前面加上展开符号（该参数就会变成其余参数），就能把多传入的参数值以数组的形式，容纳在其余参数中。

注意，函数里只能有一个其余参数，而且一定要放在最右边。

参照：其余参数 - JavaScript | MDN

对象解构赋值

数组的解构赋值强调的是顺序，而对象的解构赋值强调的则是属性名称，属性名称必须相互对应才能够获取到值。

在对象解构赋值中，冒号前是用来对应对象的属性名称，冒号后才是真正创建的变量名称和被赋值的对象。

如何改写

把参数往前提，把关键字 function 删掉，改成箭头。
只有一个参数时可以不用小括号包起来，如果没带入参数就还是需要小括号。
如果只有单行代码而且只是要返回一个值的情况下，可以省略大括号及 return。
箭头函数没有 arguments 对象，所以如果要传入多个参数值时，可以在箭头函数的小括号内使用其余参数。

与传统函数最不同的地方：this 绑定差异

  • 传统函数：this 取决于函数调用的方式
  • 箭头函数：this 取决于被定义时所在的对象，「箭头函数没有自己的 this」，因此它都是采用其同层级的 this 来作用。

写 Vue methods 时最好使用传统函数搭配缩写，因为使用箭头函数的话，this 指向的可能不是 Vue 实例。

参照：[笔记] JavaScript ES6 中的箭头函数（arrow function）及对 this 的影响

常用数组方法

forEach() 与 map()

两者很像，但 forEach() 不会返回值，而 map() 会返回一个新的数组。
map() 的 callback 函数里需要使用 return 来返回运算后的结果，且也需要一个变量来接收 map() 执行后的新数组。

filter()

filter() 与 find()：filter() 返回的是一个新数组且里面包含所有符合条件的元素，而 find() 只会返回第一个符合条件的元素值。因此，find() 较适合用于搜寻一个特定的值。

every()

所有元素都符合条件才会返回 true。

some()

部分元素有符合条件就会返回 true。

reduce()

用于累加或比较值的大小。

累加

reduce() 第一个参数是一个 callback 函数，第二个参数是累加的起始值。

callback 函数的参数中，第一个参数为「前一个元素的值」，如果没有前一个元素，就使用 reduce() 的第二个参数。
