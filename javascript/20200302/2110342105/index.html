[JS] 讲座笔记：JS Promise 实战教学

发表于 2020-03-02 分类于 JavaScript Disqus：

本篇笔记来自 2020.2.26 六角学院在线研讨会，讲者为偷米骑巴哥的 Tommy。在这一次讲座中，Tommy 老师为大家复习了异步行为与 Queue 的概念，并接续介绍了使异步行为依次进行的四种方法。

当我们有 3 个 setTimeout() 时，我们可以使它们按照顺序执行；但是当我们有 3 个 AJAX 时，由于变因太多、无法确定各自返回的时间，因此不一定能照顺序执行。

要解决异步无法依次执行的问题，第一个方法是使用 callback function。

让异步依次执行 解法一：callback

三个 setTimeout() 个别用 function 包起来，且各个 function 都带入一个 callback 参数。

调用 function A 时，同时定义 callback 的任务内容，如此一来就可以先印出 'A' 再印出 'OK'。

运用这个原理，就可以把 function B 当作 function A 的 callback，把 function C 当作 function B 的 callback。

但是这种做法一旦遇到太多函数要依次执行时，就会变成 callback hell，将会很难去分辨代码。

让异步依次执行 解法二：Generator

  • 在 function 后面加一个 *，执行时会得到一个 generator 对象。
  • 在 for 循环中使用 yield 关键字：代表暂停，先跳出 function，等之后在 function 外面用 函数名称.next() 调用时，才会再回到 function 内部继续执行。
  • generator 对象会带出 done 特性
  • arguments : 类数组对象，可获取所有传入 function 的参数
  • 递回：在函数里调用函数本身

让异步依次执行 解法三：Promise

  • 一个封装 Promise 的函数
  • Promise 的 callback function 要带入两个参数：resolve (成功时调用)，以及 reject (失败时调用)。

异步成功时，就会执行 resolve；resolve 执行后，就会执行 .then() 的内容；反过来说，.then() 的执行仰赖 resolve 是否执行。

异步失败时，Promise 会执行 reject，reject 必须准备对应的函数，这个函数是针对单一的 Promise，在失败时执行的方案。

在异步失败时执行对应的行为也能用 catch 达成，catch 的意思是，只要其中一个 Promise 没成功执行，就跳到 catch。

让异步依次执行 解法四：async…await

  • ES7 语法，要搭配 Promise 使用
  • async + function：声明这个函数是异步
  • await + Promise：依次执行函数
  • 条件：async 跟 await 一定要搭配使用，不能只用 await 却不用 async。

reject 时与 try...catch 搭配使用，reject() 括号内的内容会传到 catch(e) 的 e 参数，也可以直接在 reject() 括号内放入 Error 对象（JS 原生错误对象）。
