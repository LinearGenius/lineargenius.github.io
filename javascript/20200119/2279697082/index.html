[JS] 讲座笔记：函数式程序设计

发表于 2020-01-19 更新于 2020-02-10 分类于 JavaScript Disqus：

这篇笔记来自于 2020.1.9 六角学院的在线研讨会，讲者为苏泰安老师，老师不只讲解了如何善用函数来帮助代码更简洁，也介绍了一些以函数为编写基础的语言（例如 Elixir），不过由于我对 Javascript 以外的语言并不了解，所以这篇笔记并不会着墨于其他语言。

前言

在 JavaScript 函数是一级公民，可以传入另一个函数作为参数。
传入其他函数作为参数的函数称为 Callback function。
而接收其他函数当作自己的参数的则称为高阶函数。

高阶函数(High order function)：处理函数的函数

高阶函数三大台柱：map()、reduce()、filter()

map()

对 A 数组进行某种处理，返回处理过后的新数组 B。

filter()

从 A 数组中筛选符合某条件的值，符合条件的值以新数组 B 返回。

reduce()

有顺序上的依赖，依次对数组内的值进行处理（累加、相乘等等）。

循环跟 map()、reduce()、filter() 的差别：

循环一定要依次对值进行处理，就像手摇店员对一个接一个的客人进行结帐；数组方法不强调值的处理顺序，只强调处理的手法。

闭包 Closure

利用闭包（closure）的作法，让函数有自己的私有变量，避免函数受到外在值的变动而被污染。当你看到一个函数内 return 了另一个函数，通常就是有用到闭包的概念。
参照：Robert Nyman: 解释 JavaScript 的 scope 及 closures、深入浅出了解 JavaScript 闭包（closure）

学员提问

Q: 具名函数 VS 匿名函数的区别？
A: 具名函数可提升，匿名不能提升（会 undefined）。
