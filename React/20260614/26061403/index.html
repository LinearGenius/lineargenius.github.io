[React-Konva] 结合图像分割实现自动抠图编辑器

发表于 2026-06-14 分类于 React Disqus：

把图像分割模型输出的蒙版转换为透明前景，并用 react-konva 完成拖拽、缩放、背景替换、笔刷修边和高清导出。

系统拆成推理与编辑两层

图像分割负责为每个像素预测前景概率，编辑器负责把蒙版转换为可交互图层。两层通过原图尺寸、蒙版尺寸和坐标变换连接。模型可以在浏览器 Worker、服务端 GPU 或云推理服务运行，UI 不应依赖具体模型实现。

输入图片先做方向与尺寸归一化

读取文件后校验真实类型和像素总量，处理 EXIF 方向，再生成用于推理的缩略图。编辑仍保留原图；蒙版在导出阶段映射回原尺寸。Object URL 使用结束后及时 revoke，避免大图反复上传造成内存泄漏。

把概率蒙版变成 Alpha

模型常返回 0 到 1 的概率数组。阈值决定边缘硬度，也可以用平滑曲线保留半透明头发。将原图 RGB 与蒙版 Alpha 写入离屏 Canvas，得到透明前景位图。

用 react-konva 组织图层

Stage 保存画布坐标系；背景、透明前景、修边蒙版和选区工具放在独立 Layer。React 状态只保存可序列化的变换参数，ImageBitmap、Konva Node 等对象放在 ref。频繁笔刷点位可批量提交，避免每个 pointermove 都触发整棵 React 树更新。

选择、缩放与坐标换算

Transformer 需要手动绑定选中的 Konva 节点。缩放结束后把 scaleX/scaleY 合并进业务宽高，再把节点 scale 重置为 1。舞台缩放、图片变换和原图像素是三套坐标系，修边笔刷必须通过节点逆变换映射到蒙版坐标。

修边笔刷修改蒙版

保留原始概率蒙版和用户修正层。恢复笔刷把修正值设为前景，擦除笔刷设为背景，羽化笔刷改变邻域权重。操作记录为笔画命令以支持撤销；达到一定数量后合并检查点，避免历史无限增长。

高清导出与跨域限制

导出时按原图分辨率创建离屏舞台或 Canvas，重放背景、变换与最终蒙版。预览只需屏幕分辨率，导出再做高质量重采样。远程图片必须返回允许的 CORS 响应头并以 anonymous 加载，否则 Canvas 会被污染，toDataURL 或读取像素将失败。

性能与失败恢复

推理放进 Worker，使用可转移的 ImageBitmap 或 ArrayBuffer；大图设置像素上限；快速连续上传时用任务 ID 丢弃旧结果。保存原图引用、模型版本、阈值、变换和笔画命令，刷新后可以恢复编辑，而不是只保存最后一张低清预览。
