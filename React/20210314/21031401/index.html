[React] 用 Hooks 整理组件状态与副作用

发表于 2021-03-14 分类于 React Disqus：

Hooks 让函数组件拥有状态与生命周期能力，但真正的价值不是少写一个 class，而是把同一件事的状态和副作用放在一起。本文用一个搜索列表拆解最常见的写法。

状态只保留最小集合

能由现有数据计算出的值不必再放进 state。输入词和结果需要保存，结果数量可以在渲染时直接计算。

Effect 用于同步外部系统

useEffect 适合请求、订阅和操作浏览器 API。依赖项应完整填写，并在组件卸载或关键词变化时取消旧请求。

何时抽成自定义 Hook

当多个组件共享“状态 + 副作用”的组合时，再抽成 useSearch。自定义 Hook 复用的是逻辑，每个调用者仍有独立状态。Hook 必须在组件顶层调用，不能放进条件语句。

检查清单

  • 不要把可计算值重复存入 state。
  • Effect 中使用的响应式值都写入依赖项。
  • 订阅、计时器和请求都提供清理函数。
  • 先保证逻辑清楚，再考虑 useMemo。
