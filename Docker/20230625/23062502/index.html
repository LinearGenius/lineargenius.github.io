[Docker Compose] 组合 Node.js、PostgreSQL 与 Nginx

发表于 2023-06-25 分类于 Docker Disqus：

Compose 的价值是把多个容器的运行方式写进一个可审查的文件。下面用 API、PostgreSQL 和 Nginx 组成一个最小服务栈。

服务间使用服务名通信

容器内部的数据库地址应写成 db:5432，而不是 localhost。localhost 永远指向当前容器本身。

健康检查不是启动顺序

容器启动不代表服务已经可用。数据库需要 healthcheck，API 也应提供轻量的 /health，让代理和部署平台判断实例状态。

持久化与密钥

数据库数据放在命名卷中，应用源代码不在生产环境挂载。密码放在宿主机环境或部署平台的密钥系统中，不提交到 Compose 文件。

Nginx 只暴露一个入口

通常只把 80/443 映射到宿主机，API 和数据库留在内部网络。Nginx 负责 TLS、压缩和反向代理，应用继续专注业务。
