确认 media query 断点

media query 到底要写在一起还是分开写

同一个 <div> 就写在一起，包含该 <div> 的子元素。

不要习惯性写死高度

在 PC 版上是可以写固定高度的，因为版面不会随屏幕大小而变化。但是要记得在 media query 中多加一行 height: auto，让内容自适应延伸。
