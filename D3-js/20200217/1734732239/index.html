D3.js 超超超基础入门

发表于 2020-02-17 分类于 D3.js Disqus：

之前接案时为了要实现一个动画效果而学过一点 D3.js，虽然最后没有派上用场，但当时我写下一些入门笔记，如果你没学过 D3.js 而想要尝试的话，可以参考这篇笔记。

什么是 D3.js

D3.js（Data-Driven Documents）是一个使用动态图形进行资料视觉化的 JavaScript 程式库。与 W3C 标准相容，并且利用广泛实现的 SVG、JavaScript 和 CSS 标准⋯⋯最常被运用在线上新闻网站呈现互动式图形、呈现资料资料的图表和呈现含有地理资讯的资料。——维基百科

简单来说，D3.js 能以图像的方式来呈现资料，并用资料来驱动 DOM。

SVG 标签

D3.js 是用 SVG 来绘制图像的，所以需要具备一些 SVG 绘图的背景知识。SVG 与 HTML 一样是有标签的，以下就是常见的 SVG 标签：

  • <text> - 文字标签
  • <circle> - 圆形标签
  • <line> - 线段标签
  • <path> - 弧形标签
  • <g> - 整合以上的物件，在 <g> 里面可以放各类型的标签

创建 D3.js 画布

首先先来了解如何用 D3.js 选取 DOM。

  • 选取单个 DOM：d3.select(‘.className’)
  • 选取多个 DOM：d3.selectAll(‘.className’)

了解如何选取 DOM 后，接著先选取一个空的 <div>，动态新增一个 SVG 画布，再用 attr() 动态加上属性来设定宽高，注意，attr() 内的格式是物件。
