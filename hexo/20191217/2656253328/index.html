[Hexo] 使用 NexT 主题如何在文章中内嵌 Codepen

发表于 2019-12-17 更新于 2019-12-21 分类于 Hexo Disqus：

估狗估不到什么东西，还好自己有摸索成功，干脆来发一篇！

在搬运 Medium 文章过来的过程中遇到一个问题，就是我之前在 Medium 写文的时候超常 embed Codepen 的，毕竟有些效果真的有 Demo 辅助说明会比较好。
但在 hexo NexT 的环境下要怎么嵌入 Codepen 哩？

第一次踩雷

我首先找到这篇文章： Hexo NexT：在文章中嵌入 CodePen或 jsFiddle，但是我下载完套件后，按照文中的方式在文章里插入模板，却跑出一堆错误信息，整篇文章的内容都无法渲染。

所以我只好舍弃这个方法，跑去翻翻 NexT 官方文件：标签外挂（Tag Plugins）。
看到官方有提供插入 iframe 的语法，我就想说 Codepen 也有提供 iframe 代码，说不定行得通。

宽度跟高度的数值都是从 Codepen 提供的代码中取出来的。

嗯…… Codepen 画面是出来了，但尺寸很有问题。

终于成功啦

最后，我尝试把 Codepen 提供的代码中，<iframe> 的 src 值取出来，放到 Next iframe 语法的 url 位置，而 [width] 跟 [height] 都去掉。

嵌入成功！
